# 0006. ブランド表記・著作権ポリシー（個人ファンサイトとしての立ち位置）

- **Status**: Accepted
- **Date**: 2026-05-06
- **決定者**: @RM0428MR

## Context

本サイトは「カルピス」を題材にした **個人運営の架空レビュー日誌**。題材であるカルピスは実在の登録商標（アサヒ飲料株式会社）であり、以下のリスクが存在する。

- **商標**：「カルピス／CALPIS」「公式ロゴ」「青い水玉模様（七夕・天の川モチーフ）」「カラダにピース」等のスローガン
- **著作権**：公式パッケージ写真・公式PRビジュアル・パッケージ上のイラスト・ロゴデザインそのもの（美術の著作物）
- **誤認リスク**：サイト名・ドメイン・体裁が公式に見える / 企業の公式アカウントと誤解される

公開前に「どこまでがOKでどこからがNGか」を一度明文化しておかないと、画面別実装で表現がブレる。特に AI生成画像の流入が増えており、ChatGPT 等で生成した「公式そっくりな画像」は商標・著作権の二重リスクになるため、独立した方針が必要。

## Decision

**「商品名は呼ぶ・公式ビジュアルは一切使わない・サイト表記名は愛称ベース・非公式宣言を必ず明示」** の4本柱で運営する。

| 領域 | 方針 |
|---|---|
| 内部リポジトリ名 | `Review-Calpis` のまま（非公開・内部用） |
| 公開サイト名（表向き） | カルピスを直接含めない愛称（例：`乳酸菌日誌` / `白いあれ日誌` / `すきな飲み物日誌` 等から最終決定） |
| ドメイン | サイト名と揃える。`calpis-*` 系は使わない |
| ロゴ・キャラクター | 自作の手書き風のみ（`claude-design/assets/calpis_bear.png` 等） |
| 公式ロゴ・公式パッケージ画像 | **一切使用禁止**（参考としてもリポジトリにコミットしない） |
| 商品名の本文中表記 | 「カルピス」と呼んで構わない（指示的使用 / nominative use の範囲） |
| 写真 | ① 自作イラスト・手書き風モック（推奨）／ ② 自分で撮影した実物写真（可）／ **③ AI生成のパッケージ模写（禁止）** |
| 公式の青水玉模様 | パッケージそのものを連想させるドット配置・色は再現しない。装飾としての水玉は色相を変えて使う |
| 免責表記 | 全ページのフッターに以下を必ず表示：<br>「本サイトは個人運営のファンサイトであり、アサヒ飲料株式会社およびその関連会社とは一切関係ありません。」 |
| About / 利用規約 | 同趣旨をAboutページの冒頭にも明記 |

## Alternatives

| 候補 | Pro | Con |
|---|---|---|
| **本案：愛称ベース + 非公式宣言 + 自作ビジュアル限定** | 商標・著作権リスクを最小化、トンマナ（手書き日誌）にも合致、AI生成模写リスクも遮断 | サイト名で「カルピス」と直接謳えないので検索流入は弱くなる |
| 商品名を全面に出す（`カルピス日誌` のまま公開） | ブランドの想起力が強い、検索性高 | 公式誤認・商標的使用と判断されるリスク。公開停止要請があり得る |
| 完全匿名化（商品名すら出さない） | リスクほぼゼロ | レビューサイトとして成立しない、執筆体験が損なわれる |
| 事前に企業に許諾取得 | 完全に正当化される | 個人運営の規模感では現実的でない、断られる可能性が高い |

## Consequences

- **Pro**：
  - 「個人ファンサイト」としての立ち位置がブレなくなる（公開後の実装・コピー文言の判断軸が固定）
  - AI生成・公式画像転載といった事故起こしやすい経路を明示禁止できる
  - フッター免責が共通コンポーネント化され、画面別実装で書き忘れない
  - 万が一指摘を受けた場合も「悪質な意図はなく、指摘があれば即対応する」運営姿勢を示しやすい
- **Con / 引き受けるリスク**：
  - SEO 上、商品名そのものをサイト名に含められないため流入が弱い
  - 自作イラスト中心になるため、写真リッチな見た目は諦める
  - 公開後に商標保有企業から指摘があった場合、サイト名・ドメイン・特定ビジュアルの差し替えが発生する可能性は残る（その場合は速やかに対応する前提）
- **フォローアップ**：
  - 公開サイト名を決定し、`CLAUDE.md` §プロジェクト概要・README・各設計書のサイト名表記を一括更新
  - フッター共通コンポーネントに免責文を実装（`site/src/components/SiteFooter.astro`）
  - About ページ冒頭に同趣旨を記載（設計書 `FE/デザイン/画面別詳細設計/About/` に反映）
  - `design/source/Calpis-main-image.png`（AI生成のパッケージ模写画像）は **使用禁止素材** として削除し、リポジトリから除外
  - `.gitignore` か `design/source/README.md` に「AI生成のパッケージ模写画像はコミット禁止」を明記
