# 0007. EMIEL を独立した架空ブランドとして確立する

- **Status**: Accepted
- **Date**: 2026-05-11
- **Supersedes**: [ADR/0006](0006-brand-copyright-policy.md)
- **決定者**: @RM0428MR

## Context

ADR/0006 では、本サイトを「実在ブランドのファンサイト」と位置づけ、
非公式宣言・愛称ベースのサイト名・自作ビジュアル限定の運用で IP リスクを管理する設計を採用していた。

その後、以下の判断軸に照らして方針を再検討した：

- 第三者（特に外部の閲覧者）が初見でサイトを開いたときに、
  独立した創作プロジェクトとして読める方が立ち位置がクリーンになる
- 実在ブランドを名指しで否定する免責文は、かえって実在ブランドとの関係を想起させる構造になっていた
- リブランド作業（claude-design / `site` 実装上の固有名・画像・コピーの差し替え）は完了しており、
  サイト本体としては既に独立した架空ブランド「EMIEL」として成立している

これらを踏まえ、ADR/0006 を置換し、EMIEL を完全に独立した架空ブランドとして確立する方針へ転換する。

## Decision

EMIEL を **独立した架空の乳酸飲料ブランド** として確立する。
本サイトはその架空ラインナップを個人の日記帳形式でレビューする創作プロジェクトとして位置づける。

| 領域 | 方針 |
|---|---|
| ブランド位置づけ | EMIEL = 完全な架空乳酸飲料ブランド（独立した創作物） |
| 商品名・キャラクター・ビジュアル・レビュー本文 | すべてオリジナルのフィクション |
| 実在ブランドへの直接言及 | 行わない（README / Footer / About / 本文すべて） |
| 「非公式宣言」型の免責 | 廃止。代わりにフッターでサイトの性質（架空ブランドの創作レビュー日誌）を中立的に明示する |
| 公式ロゴ・公式 PR 画像・実物商品写真 | 引き続き使用しない |
| 内部リポジトリ名 | GitHub 上は `Review-EMIEL`（ローカル `Review-Cal`）。ブランドと整合 |
| 公開運用方針 | 静的サイトとしてホスティング。一般的な検索流入やマーケティングは想定しない |
| 個人としての実在商品レビュー欲求 | 本サイトのスコープ外（本人のプライベート用途で別途処理） |

## Alternatives

| 候補 | Pro | Con |
|---|---|---|
| **本案：独立した架空ブランドとして確立** | サイトの一貫性、IP リスクの実質的解消、創作プロジェクトとしての強度 | SEO・検索流入は実質期待しない |
| ADR/0006 を維持（実在ブランドのファンサイト） | 本人の動機との一致 | 実在ブランドとの関係を否定する免責文が逆に関係を想起させる構造、対外的にクリーンに見えない |
| 完全匿名化（商品名も世界観も削ぎ落とす） | リスクほぼゼロ | 創作物としての魅力が失われる |

## Consequences

- **Pro**：
  - サイト全体（README・ADR・Footer・About・本文）が「独立した架空ブランド EMIEL の創作日誌」として整合する
  - 実在ブランドへの直接言及を排除したことで、IP リスクが実質的に解消される
  - 第三者が見たときに **単独の創作プロジェクト** として読める
  - 旧 ADR/0006 と本 ADR の対で「ブランド方針が時系列で進化した」記録が残り、設計判断の透明性が保たれる
- **Con / 引き受けるリスク**：
  - 「実在ブランドのファンサイトでは無い」と明示するため、本人の創作動機をサイト本体で語る余地が狭くなる（必要であれば About ページの世界観表現で代替する）
  - 検索流入や口コミ拡散は実質期待できない
- **フォローアップ**：
  - `README.md` を本 ADR 方針に整合（2026-05-11 完了）
  - `site/src/components/Footer.astro` の免責文を架空ブランド前提の中立表現に置換（本 ADR 採択時点で完了）
  - `site/src/content/site/about.md`「ブランドについての注意」セクションを架空ブランド前提に書き換え（本 ADR 採択時点で完了）
