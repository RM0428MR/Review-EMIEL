# CALPIS日誌 — 実装引き継ぎメモ

このプロジェクトは、乳酸菌飲料の個人レビューサイト（架空・個人運営の日誌スタイル）の **デザインモック** です。
これから Claude Code（CLI）で **実サイト化** していくフェーズに入ります。

> ⚠️ ブランド注意：「CALPIS」は実在の登録商標です。本サイトはあくまで個人の感想を集めた**ファン日誌**として運営する想定。
> 公式ロゴ・公式パッケージ画像は使わず、自作の手書き風スタイルで通すこと。商品名表記は一般名や愛称ベースに留める判断を都度すること。

---

## 1. 現在の中身（モック）

### エントリー
- `CALPIS日誌.html` — Babel in-browser で動く React モック。本番ではこの構成は捨て、ビルド有りの構成に置き換える。

### 画面（design-canvas に並んでいる）
1. **ホーム** — ヒーロー＋最新レビュー＋ランキング抜粋
2. **レビュー一覧** — カテゴリ/気分/季節フィルタ
3. **レビュー詳細** — ★評価、サブ評価レーダー、本文、商品情報
4. **ランキング** — 評価順
5. **アーカイブ** — 年月別
6. **お問い合わせ** — フォーム

### スタイル方針（要継承）
- フォント：`Klee One`（本文）/ `Caveat`（英字あしらい）/ `Yusei Magic`（補助）
- ベース色：`#f0eee9`（紙っぽいオフホワイト）
- アクセント：`#7aa9d9`（カルピス連想の薄い青）
- 雰囲気：手書き感・日誌・スタンプ・マスキングテープ
- 装飾は `stickers.jsx` に集約

### モックデータ
- `data.jsx` の `REVIEWS` 配列が暫定スキーマの素になっている

---

## 2. 実装ターゲット：ルートB（CMS連携・静的生成）

### 採用スタック
- **Astro 5** + **React アイランド**（既存 jsx を最小改修で持ち込みやすい）
- **microCMS**（Headless CMS、日本語UI、無料枠あり）
- **画像**：microCMS のメディア機能でOK（CDN込み）
- **デプロイ**：Cloudflare Pages または Vercel
- **ドメイン**：未定（後で決める）

### なぜこの構成か
- 日誌＝更新頻度はそこそこ、SEO は欲しい → **静的生成**が向く
- スマホから書きたい → microCMS のスマホ管理画面が使いやすい
- 既存モックの React コンポーネントを `client:load` でそのまま使える

## 3. 実装ステップ（Claude Code 向け指示テンプレ）

CLI を起動したら、まず以下を順に頼む想定。

### Step 0：セットアップ
```
このフォルダの内容を読んで、CLAUDE.md と SCHEMA.md の方針で
Astro + React + microCMS の新規プロジェクトを ./site に作成して。
モックの jsx は参考資料として残す（消さない）。
```

### Step 1：スキーマ確定 & microCMS連携
```
SCHEMA.md の通りに microCMS 側の API 定義を作る手順を README に書いて。
.env.example に MICROCMS_SERVICE_DOMAIN と MICROCMS_API_KEY を入れて。
src/lib/microcms.ts でクライアント実装、
src/lib/types.ts に Review 型を定義。
```

### Step 2：ページ移植
モック → Astro ページの対応：
| モック | Astroルート | データソース |
|---|---|---|
| ホーム | `/` | 最新6件 + 評価上位5件 |
| 一覧 | `/reviews` | 全件、クエリでフィルタ |
| 詳細 | `/reviews/[id]` | getStaticPaths |
| ランキング | `/ranking` | rating降順 |
| アーカイブ | `/archive` | 年月でグルーピング |
| お問い合わせ | `/contact` | Formspree か Cloudflare Forms |

各ページは Astro `.astro` をシェルにして、インタラクティブな部分（フィルタUI等）だけ React アイランド化。

### Step 3：スタイル移植
- `parts.jsx` / `stickers.jsx` の見た目を CSS Modules か Tailwind で再構築
- フォント・色・余白は `CLAUDE.md` セクション1の方針を絶対遵守
- `design-canvas.jsx` / `tweaks-panel.jsx` は本番には**持ち込まない**

### Step 4：デプロイ
- GitHub にpush → Cloudflare Pages 連携
- microCMS Webhook で更新時に自動再ビルド

## 4. 実装中に決めていいこと / ダメなこと

### 実装しながら調整OK
- 画面ごとの細かいレイアウト
- 余白・タイポのfine-tune
- 装飾（スタンプ・テープ）の量と配置
- フィルタUIの見せ方
- 追加で欲しくなった画面（タグページ等）

### 勝手に変えないでほしい
- フォント3種類の組み合わせ
- ベース色 `#f0eee9` と アクセント `#7aa9d9`
- 「日誌・手書き感」というトンマナ
- 個人の感想サイトという立ち位置（公式っぽくしない）

迷ったら**モックの該当画面に戻って参照** → それでも判断つかなければユーザーに確認。
