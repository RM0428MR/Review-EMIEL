# 06_モバイル設計

> ソース：`claude-design/pages-mobile.jsx`（1322 行、独立した React 実装）と `claude-design/uploads/{Home,review,review-detail,Ranking,Archive,Contact,Navigation}-mobile.png`、`uploads/nav-desktop.png`。

## 方針

- デスクトップ（1280px 〜）とモバイル（〜 480px）は **別レイアウト**として実装する。
- claude-design `pages-mobile.jsx` は構造的に media query での折り返しでは再現できないため、breakpoint で大きく分岐する。
- 中間幅（481〜1024px）はタブレット相当：モバイルレイアウトを横に伸ばしたものを当てる（Phase 4 で詰める）。
- ナビゲーションは、デスクトップ・モバイルとも **右上の HandGlass（カップ）をハンバーガー扱い**、クリックで Drawer（pages-2.jsx `NavigationPage` / pages-mobile.jsx `MobileNav` 由来）を開く統一仕様。

## ブレイクポイント

```css
:root {
  --bp-mobile: 768px;   /* これ以下はモバイル */
  --bp-tablet: 1024px;  /* これ以下はタブレット相当 */
}

/* 慣用：mobile-first ではなく desktop-first（既存の固定幅 grid を破壊しないため） */
@media (max-width: 768px) {
  /* モバイル時の上書き */
}
```

## Drawer（ナビゲーションメニュー）

- トリガー：**SiteHeader 右上の `HandGlass`（カップ）をクリック**。デスクトップ・モバイル共通（`pages-2.jsx NavigationPage` の右ペインを移植）。
- 表示形式：右からスライドインの side drawer（width: 430px、モバイルでは 100vw に近い）。
- 内容（pages-2.jsx 593-882 の `NavigationPage` 準拠）：
  1. close ボタン（右上 ×）
  2. ロゴクラスタ（My / カルピス / Review + HandGlass + HandBottle）
  3. nav 行 ×6（Home / Review / Ranking / Archive / Contact / About）— icon + ラベル + サブラベル + chevron
  4. SNS 行（Instagram / X / Note）
  5. 雲バンド + Bear（底部）
- 背景：dim overlay（`rgba(160,190,220,0.32)` light / `rgba(10,25,41,0.55)` dark）
- アクセシビリティ：`role="dialog"` + `aria-modal="true"`、Esc / オーバーレイクリックで閉じる、開いた瞬間はフォーカスを close ボタンに移す。

## MTabBar（モバイル底部タブ）

- 5 項目：home / review / ranking / archive / contact（about は drawer のみ、404/contact は drawer + tab）。
- アクティブ項目はラベル色 + icon が accent / 非アクティブは `--ink-muted-2`。
- 高さ 56px、`position: fixed; bottom: 0`、`background: #fff` + 上端 1px ボーダー。
- すべての画面で常時表示。drawer が開いている時は dim overlay の下に隠れる。
- safe-area inset 対応：`padding-bottom: env(safe-area-inset-bottom)`。

## MHeader（モバイルトップバー）

- 高さ 56px、`position: sticky; top: 0`、`background: #fff` + 上端 scallop wave 12px。
- 左：ロゴ（縦組み「my / カルピス / review」）コンパクト版。
- 右：HandGlass（drawer トリガー）。
- 特定画面（detail 等）のみ左に Back arrow 表示（`showBack=true`）。
- mobile での scallop wave は desktop より小さめ（amp 5px / scallops 32 程度）。

## 実装メモ

- `<MobileBottomTab>` Astro コンポーネントを `BaseLayout.astro` に必ずレンダー、CSS で `display: none` を desktop で当てる。
- `<NavDrawer>` は React アイランド（`client:load`）。HandGlass をボタン化して onClick で state 切替。
- 各画面の Astro `<style>` 内に `@media (max-width: 768px)` ブロックを追加してレイアウト分岐。
- 大変な部分は次の通り：
  - **Review詳細**：3 カラム → 1 カラムへの構造変換（IMAGE → CENTER → ASIDE の順で stack）
  - **Header**：デスクトップのフル nav 行は隠し、ロゴと HandGlass 以外は drawer に集約
  - **Footer**：variant ごとに mobile では簡素化（ranking footer 等の 3 col は中央寄せ stack）
- フォントサイズはモバイルで 1〜2px 縮める：`var(--fs-hero)` だけは `clamp(40px, 9vw, 56px)` で可変。
