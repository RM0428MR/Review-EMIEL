## タイポスケール

claude-design jsx の数値を集約。

```css
:root {
  --fs-hero: 56px;     /* HomePage hero "カルピス" / RankingPage h1 */
  --fs-hero-script: 44px; /* "my" / "review" の Caveat 大 */
  --fs-h1: 48px;       /* Contact h1 */
  --fs-h2: 32px;       /* Archive 年見出し風（本文では 22px 多用） */
  --fs-section: 22px;  /* section h2（new review, ranking 等） */
  --fs-card-title: 16px; /* card h3（Top3） */
  --fs-lead: 14px;
  --fs-body: 13px;     /* 本文（review body） */
  --fs-body-sm: 12px;  /* aside / 副情報 */
  --fs-meta: 11px;     /* タグ / メタ情報 */
  --fs-caption: 10px;  /* 日付 / count badge */
  --fs-mini: 9px;      /* タグ #hashtag */
}
```

レスポンシブで hero は `clamp(40px, 6vw, 88px)` まで伸縮可（決定ログ §デザイントークン）。

## 余白 / グリッド

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --space-8: 32px;
  --space-10: 40px;  /* セクション horizontal padding（最頻出） */
  --space-12: 48px;
  --gap-grid: 16px;  /* card grid gap default */
  --gap-section: 24px; /* section 間 */
}
```

- セクション padding：`0 40px`（左右）/ 画面によっては `padding: '20px 40px 40px'`。
- カード：`padding: 14〜22px`、`borderRadius: 12〜18`、`border: 1px solid rgba(168,200,232,0.4)`。

## 装飾ルール

### 角丸
| 用途 | 値 |
|---|---|
| ピル（chip / button） | `999px` |
| カード | `12〜20px`（多くは `14` / `18`） |
| 入力欄 | `10px` |
| 写真フレーム | `10〜18px` |

### ボーダー
- 既定：`1px solid rgba(168,200,232,0.4)`（cardBorder light）。dark 時は `1px solid rgba(168,200,232,0.15)`。
- 区切り：`1px dashed rgba(168,200,232,0.3)`（リスト行間, sub評価上端）。

### 影
- カード：`0 2px 8px rgba(122,169,217,0.06)`（弱め、紙感を保つ）。
- フッター内 subscribe ボタン：`0 2px 4px rgba(60,90,130,0.08)`。
- フォーム送信ボタン：`0 4px 12px rgba(122,169,217,0.3)`。
- ステッカーパネル：`0 8px 32px rgba(60,90,130,0.24)`（編集モード専用、本番非対応）。

### 手書き要素
- `Underline`：`stroke=accent`, `strokeWidth=2`, 波形 path。見出し直下や button 装飾に。
- `WashiTape`：斜め repeating-gradient + clipPath で粗いエッジ。card 上部に `position:absolute; top:-10px` で貼る。
- `SpeechBubble`：dashed border (`1.5px dashed`) + 三角しっぽ。`stroke=accent-soft` 既定。
- `BearDoodle` / `BearSitting`：`assets/bear-doodle.png` の透過 PNG を `<img>` として使用（parts.jsx:7-23）。本番は microCMS Asset 経由ではなく **public/static** 配置（更新頻度ゼロのため）。
- `HandBottle` / `HandGlass`：`assets/hand-bottle.png` / `hand-cup.png`。同上。

### 水玉散らし
- `PolkaDots` コンポーネント（parts.jsx:395-444）。シード固定で stable な散布。
- カラーは `['#9ec6ec','#bcd9ee','#7eb4dc']` の 3 段階。
- 配置エリアに対して `count` を density として渡す。

### scallop wave
- ヘッダー上端：64 個の small scallops。22px 高、`waveDark = #7aa9d9` 単色（parts.jsx:472-496）。
- フッター上端：`CloudWave` の Q-curve scallop（parts.jsx:573-604）。`fill = wave (#cfe3f2)`。

## ステッカー機能の扱い

`stickers.jsx` の StickerLayer / StickerPalette / dragController は **編集用ツール**。本番には移植しない（CLAUDE.md に明記）。装飾のスタンプ感は静的配置（`PolkaDots` / `WashiTape` / `BearDoodle`）で代替する。

## CSS Modules + CSS変数 採用方針

- Tailwind は不採用（決定ログ採用スタック）。手書き感の SVG / dashed と相性悪いため。
- `:root` に上記変数を定義し、各コンポーネントは `*.module.css` でセマンティッククラス + `var(--xxx)` を参照。
- インラインstyle は jsx そのまま持ち込む過渡期だけ許容。実装段階で順次 module 化。
