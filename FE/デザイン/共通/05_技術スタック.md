## 採用スタック

| 層 | 技術 | 備考 |
|---|---|---|
| フレームワーク | **Astro 5** | 静的サイト生成、ファイルベースルーティング |
| UI（島） | **React 18+** | フィルタ UI / フォーム / Like ボタンのみ。それ以外は Astro の `.astro` |
| CMS | **microCMS** | 日本語UI、無料枠、スマホ管理画面 |
| スタイル | **CSS Modules + CSS変数** | Tailwind は採用しない（手書き感 SVG / dashed と相性悪い） |
| フォント | Google Fonts | Klee One / Caveat / Yusei Magic / RocknRoll One / M PLUS Rounded 1c |
| 検索 | 採用しない | 規模が小さいうちはフィルタ・アーカイブで十分。必要になったら Pagefind 等を後乗せ |
| アイコン / 装飾 | 自作 SVG（parts.jsx 由来） | 公式ロゴ等は使わない |
| 写真 | microCMS Asset（CDN） | クエリで `?w=&h=&fit=crop&fm=webp` |
| デプロイ | **Cloudflare Pages** | 帯域無制限、PR プレビュー |
| フォーム送信 | **CFP Function + Cloudflare Turnstile + Discord Webhook** | Discord 通知でスマホ即時把握 |
| アナリティクス | **Cloudflare Web Analytics** | プライバシー配慮型、Cookie同意不要 |
| ドメイン | TBD（独自 or `*.pages.dev`） | – |

## ビルド & デプロイ

1. ローカル：`pnpm dev` で Astro dev server。microCMS API は `.env.development` に書く。
2. push → GitHub `main`：Cloudflare Pages の Production build トリガー。
3. microCMS Webhook：コンテンツ更新時に CFP の Deploy Hook を叩いて再ビルド。
4. ビルド時 `astro build`。
5. CFP Function（`functions/api/contact.ts`）は `astro/cloudflare` adapter で同居。

| `/404` | 静的 | – |

## アクセシビリティ / 性能ガイド

- 画像は `<img>` ではなく `<Image>` (`astro:assets`) で width/height/loading 必須。`heroImage` は eager、card は lazy。
- 装飾 SVG は全て `aria-hidden="true"`（jsx でも揃っている）。
- フォント：preload は `Klee One 400` のみ。Caveat / RocknRoll One は font-display: swap。
- ライトハウス Performance ≥ 90 を目標。

## CI

- GitHub Actions：`pnpm install && pnpm build && pnpm test --if-present`。
- Lint：ESLint（Astro plugin）+ Prettier。
- 型チェック：`astro check`。
