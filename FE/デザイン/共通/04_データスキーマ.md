# 04_データスキーマ

> ソース：`claude-design/data.jsx` の `REVIEWS` 配列 + 決定ログ（2026-05-06）合意事項。microCMS 側の API スキーマと、TypeScript 型定義を併記。

## microCMS API：`reviews`

### API 種類
- リスト形式（一商品 1コンテンツ）。

### フィールド一覧

| フィールドID | 種類 | 必須 | 値域・備考 |
|---|---|---|---|
| `slug` | テキスト | ✓ | 半角英小+ハイフン。URL の `[slug]`。`data.jsx:id` を踏襲（例: `rich`, `melon`, `peach`） |
| `name` | テキスト | ✓ | 商品名（例: `THE RICH`、`白桃`、`ラムネ`） |
| `date` | 日時 | ✓ | レビュー日。表示は `YYYY.MM.DD` |
| `variant` | セレクト型（単一） | ✓ | `pet` / `carton` / `cup` / `plastic` |
| `tint` | テキスト | ✓ | hex（例: `#fff5e8`）。BottlePlaceholder の中身色 |
| `accent` | テキスト | ✓ | hex（例: `#c89a6a`）。商品ごとアクセント |
| `rating` | 数値 | ✓ | 0.0 - 5.0、0.5 刻み |
| `badge` | テキスト |   | `NEW` 等（任意） |
| `oneLiner` | テキスト | ✓ | 一言まとめ |
| `body` | リッチテキスト |   | レビュー本文。HTML 出力、画像埋め込み可 |
| `tags` | 複数テキスト |   | 自由タグ（例: `新商品`, `濃厚`, `ご褒美`） |
| `cat` | セレクト型（単一） | ✓ | `定番` / `期間限定` / `コラボ` / `その他` / `新商品` |
| `mood` | セレクト型（複数） |   | `さっぱり` / `濃厚` / `フルーティー` / `甘め` / `すっきり` |
| `season` | セレクト型（単一） | ✓ | `春` / `夏` / `秋` / `冬` / `通年` |
| `heroImage` | 画像 |   | 詳細ページ・カードのメイン画像。microCMS Asset。複数アスペクトの自動変換は CDN クエリで `?w=...&fit=...` |
| `gallery` | 複数画像 |   | 詳細ページのサムネ 4 枚（モックは同一画像 4 連だが本番は別カット推奨） |
| `subAmasa` | 数値 |   | 甘さ 0-5、0.5 刻み |
| `subKoisa` | 数値 |   | 濃さ |
| `subSappari` | 数値 |   | さっぱり感 |
| `subMilk` | 数値 |   | ミルク感 |
| `subRepeat` | 数値 |   | リピしたい度 |
| `infoReleased` | テキスト |   | 例: `2024年4月16日` |
| `infoVolume` | テキスト |   | 例: `470ml` |
| `infoType` | テキスト |   | 例: `乳酸飲料` |
| `officialUrl` | テキスト |   | 「公式サイト →」ボタン先 |

### 設計上の決定（決定ログ §データスキーマ）

- **sub評価は個別フィールド × 5**。JSONカスタムフィールドではない（管理画面のスライダーUXのため）。
- **info も個別フィールド × 3**。同じ理由。
- **未設定 sub項目は表示しない**：
  - 1〜4 個埋まっている場合、空の行は描画スキップ。
  - 全 5 項目が空の場合、「サブ評価」セクションごと非表示。
- `body` は **microCMS リッチテキスト**。HTML を `set:html` で流し込む。
- `mood` は複数選択（`data.jsx` でも `mood: ['さっぱり', 'すっきり']` の配列）。

### 一覧 / 並び順

- 既定：`-date` 降順。
- 「評価順」並び：`-rating, -date`。
- フィルタは `cat` / `mood[contains]` / `season` の組み合わせ。

## TypeScript 型

```ts
// src/lib/types.ts

export type Variant = 'pet' | 'carton' | 'cup' | 'plastic';
export type Cat     = '定番' | '期間限定' | 'コラボ' | 'その他' | '新商品';
export type Mood    = 'さっぱり' | '濃厚' | 'フルーティー' | '甘め' | 'すっきり';
export type Season  = '春' | '夏' | '秋' | '冬' | '通年';

export interface MicroCmsImage {
  url: string;
  width: number;
  height: number;
}

export interface SubRatings {
  subAmasa?:   number;  // 甘さ
  subKoisa?:   number;  // 濃さ
  subSappari?: number;  // さっぱり感
  subMilk?:    number;  // ミルク感
  subRepeat?:  number;  // リピしたい度
}

export interface ProductInfo {
  infoReleased?: string; // 発売日
  infoVolume?:   string; // 内容量
  infoType?:     string; // タイプ
}

export interface Review extends SubRatings, ProductInfo {
  id:        string;       // microCMS 内部ID
  slug:      string;
  name:      string;
  date:      string;       // YYYY-MM-DD
  variant:   Variant;
  tint:      string;       // hex
  accent:    string;       // hex
  rating:    number;       // 0-5
  badge?:    string;
  oneLiner:  string;
  body?:     string;       // HTML
  tags?:     string[];
  cat:       Cat;
  mood?:     Mood[];
  season:    Season;
  heroImage?: MicroCmsImage;
  gallery?:   MicroCmsImage[];
  officialUrl?: string;
}

// 表示時に sub 評価を「項目名: 数値」のラベル付き配列にする util
export const SUB_LABELS: Array<[keyof SubRatings, string]> = [
  ['subAmasa',   '甘さ'],
  ['subKoisa',   '濃さ'],
  ['subSappari', 'さっぱり感'],
  ['subMilk',    'ミルク感'],
  ['subRepeat',  'リピしたい度'],
];

export function visibleSubRatings(r: Review): Array<{ label: string; value: number }> {
  return SUB_LABELS
    .filter(([k]) => typeof r[k] === 'number')
    .map(([k, label]) => ({ label, value: r[k] as number }));
}
```

## 「似ているかも？？」ロジック（決定ログ §機能ロジック）

```ts
export function getSimilarReviews(r: Review, all: Review[], limit = 3): Review[] {
  return all
    .filter(x => x.slug !== r.slug)
    .filter(x => x.cat === r.cat || (x.tags?.some(t => r.tags?.includes(t)) ?? false))
    .sort((a, b) => b.rating - a.rating)
    .slice(0, limit);
}
```

## microCMS クライアント

```ts
// src/lib/microcms.ts
import { createClient } from 'microcms-js-sdk';
import type { Review } from './types';

export const cms = createClient({
  serviceDomain: import.meta.env.MICROCMS_SERVICE_DOMAIN,
  apiKey:        import.meta.env.MICROCMS_API_KEY,
});

export async function listReviews(query?: { limit?: number; offset?: number; orders?: string; filters?: string; }) {
  return cms.getList<Review>({ endpoint: 'reviews', queries: query });
}
export async function getReviewBySlug(slug: string) {
  const res = await cms.getList<Review>({ endpoint: 'reviews', queries: { filters: `slug[equals]${slug}`, limit: 1 } });
  return res.contents[0];
}
```
