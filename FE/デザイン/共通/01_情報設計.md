# 01_情報設計

> ソース：`claude-design/parts.jsx`（SiteHeader / SiteFooter / FooterNav）、`pages-1.jsx`、`pages-2.jsx`、`uploads/01-home.png〜06-contact.png`、`uploads/nav-desktop.png`

## サイトマップ

```
/                       Home（最新6 + Top3 + アーカイブ抜粋）
/reviews                Review一覧（カテゴリ/味/季節フィルタ + ページネーション）
/reviews/[slug]         Review詳細（一商品 1ページ）
/ranking                Ranking（Top3 + 4テーマ別Top3 + my favorite）
/archive                Archive（年別/月別 toggle）
/contact                Contact（フォーム）
/about                  About（モックなし、共通スタイルで起こす）
/404                    Not Found
```

`SiteHeader.items` の宣言は `['home','about','review','ranking','archive','contact']`（parts.jsx:463）。`/about` を含むため `/about` は MUST 実装、`/404` は補助。サイト内検索は採用しない（後述）。

## URL 規約

- Review詳細は `/reviews/[slug]`。`slug` は microCMS `Review.slug`（半角英小+ハイフン）。`data.jsx` の `id` （例: `rich`, `melon`, `peach`）を slug の素として転用。
- カテゴリ・気分・季節フィルタは `/reviews?cat=定番&mood=さっぱり,すっきり&season=夏`（複数選択可なものは `,` 区切り）。
- アーカイブの年絞り込みは `/archive?year=2024`、月別 mode は `/archive?mode=month`。
- Ranking のテーマ「もっと見る →」は `/reviews?mood=さっぱり` 等のフィルタ済み一覧へ遷移。

## グローバルナビゲーション

- デスクトップ：`SiteHeader`（parts.jsx:462-542）。左ロゴ（HandGlass + "my CALPIS日誌 review"）/ 中央 nav 6項目（home, about, review, ranking, archive, contact）/ 右に **HandGlass = ハンバーガー扱い**（クリックで `NavDrawer` 開く）。
- アクティブ項目はラベル下に `Underline` の手書き波線（accent #7aa9d9）。
- ヘッダー上端には scallop wave（`waveDark` 色）が 22px 帯で常時表示（parts.jsx:472-496）。
- モバイル：MHeader（簡素 top bar、左ロゴ + 右 HandGlass）+ `MobileBottomTab`（home / review / ranking / archive / contact 5 項目）。HandGlass クリックで Drawer 開くのはデスクトップと同仕様。詳細は [06_モバイル設計.md](06_モバイル設計.md)。
- Drawer の中身は `pages-2.jsx NavigationPage`（593-882）の右ペインを移植：close ボタン + ロゴクラスタ + nav 6 行 + SNS + 雲帯 + Bear。

## フッター（4 variant）

`SiteFooter` は `variant` 引数で 5形態を切替（parts.jsx:624-953）。各画面の SiteFooter は CLAUDE.md の画面表に合わせて以下を採用。

| variant | 採用画面 | 中身 |
|---|---|---|
| `home` | Home | scallopクラウド + subscribe(L) / BearSitting(C) / follow me + 浮きBottle(R) + nav + © |
| `review-list` | Review一覧 | 帯なし、左下に BearSitting + 右下に HandBottle のみ |
| `review-detail` | Review詳細 | `<footer style={{ height: 24 }}/>` のみ（高さ稼ぎ）。一覧戻りリンクと吹き出しはページ本体側 |
| `ranking` | Ranking | scallopクラウド + 中央 SNS 案内 + Bottle + nav + © |
| `archive` | Archive | scallopクラウド + nav + © のみ |
| `contact` | Contact | scallopクラウド + Bottle + 吹き出し + follow me + Bear + メルマガ + 吹き出し + Glass + nav + © |

About / 404 は新規。**About → `home` variant** / **404 → `archive` variant**（最小） を踏襲する。

## 検索方針

サイト内検索は採用しない。レビュー数が少ないうちはカテゴリ・味のタイプ・季節フィルタ（`/reviews`）+ 年月アーカイブ（`/archive`）+ テーマ別ランキング（`/ranking`）で十分カバーできる判断。レビュー数が増えて必要性が出てきた段階で Pagefind 等の後乗せを再検討する。

## OGP / メタ情報

- 全ページ共通：
  - `<title>` ＝ `{ページタイトル} | my CALPIS日誌 review`
  - `description`：「カルピスを愛しすぎている個人運営の架空のレビュー日誌サイト」一文をベース。
  - OGP画像：MVP 時点は固定の手書き風カバー 1 枚（`assets/calpis_bear.png` を起こした 1200×630 を 1 枚用意）。
  - 各レビュー詳細の `og:image` は `Review.heroImage` の microCMS CDN URL を `?w=1200&h=630&fit=crop` で取得。
- ロケール：`<html lang="ja">` 固定（CLAUDE.md「日本語のみ」）。

## ブランド注意（ヘッダー文言）

- ロゴは「my / カルピス / review」3行構成（parts.jsx:501-509）。
- 「カルピス」だけ `RocknRoll One` / `M PLUS Rounded 1c` を使用（pages-1.jsx:40 / pages-2.jsx:698）。
- 公式CALPISロゴ・公式パッケージ画像は使わない。本文の表記は "カルピス {商品名}" の手書き感で統一。
