# 03_コンポーネント設計

> ソース：`claude-design/parts.jsx`（共通部品）、`pages-1.jsx` の `ReviewCard` / `FilterGroup` / `FilterRow` / `FilterCheck`。本番では Astro `.astro` のテンプレートと React アイランドに分けて持ち込む。

## レイヤー分け

| レイヤー | 役割 | 例 |
|---|---|---|
| Layout | 全画面で再利用するシェル | `SiteHeader`, `SiteFooter`, `PageWrap`, `NavDrawer`（共通）, `MobileBottomTab`（モバイルのみ表示） |
| Building block | 装飾 + 形状 | `BearDoodle`, `BearSitting`, `HandBottle`, `HandGlass`, `Cloud`, `WashiTape`, `SpeechBubble`, `Underline`, `PolkaDots`, `DotPattern`, `ScatterDecor`, `RankNumber`, `HeartIcon`, `HeartsRating` |
| Data UI | データ駆動 | `ReviewCard`, `BottlePlaceholder`, `ProductPhoto`, `PhotoPlaceholder`, `FilterGroup`, `FilterRow`, `FilterCheck` |
| Page | ルート | `HomePage`, `ReviewListPage`, `ReviewDetailPage`, `RankingPage`, `ArchivePage`, `ContactPage`, `NavigationPage` |

### Drawer / BottomTab（共通レイアウト）

- **`NavDrawer`**（React アイランド）：右上の HandGlass をクリック → 右からスライドインの side drawer。中身は `pages-2.jsx NavigationPage` の右ペイン（ロゴクラスタ + nav 6 行 + SNS + 雲帯 + Bear）。デスクトップ・モバイル共通仕様（width が変わるだけ）。`role="dialog"` + Esc キー / オーバーレイクリックで close。
- **`MobileBottomTab`**：モバイルのみ表示する fixed bottom tab。home / review / ranking / archive / contact の 5 項目（about は drawer のみ）。`@media (max-width: 768px)` で出現、デスクトップは `display: none`。詳細は [06_モバイル設計.md](06_モバイル設計.md)。

## Layout

### SiteHeader
- `parts.jsx:462-542`。props: `active` / `dark` / `illust` / `hideLogo`。
- 構造：上端 scallop wave SVG（22px）→ ヘッダー本体（左ロゴ / 中央 nav / 右アイコン）。
- アクティブ判定はラベル下の Underline 表示で示す。
- 実装メモ：Astro `<Header active={...} />` props。アクティブ判定はサーバ側 `Astro.url.pathname` で算出。

### SiteFooter
- `parts.jsx:624-953`。props: `dark` / `illust` / `variant`。
- variant：`home`（既定） / `review-list` / `review-detail` / `ranking` / `archive` / `contact`。
- 共通要素：`CloudWave`（parts.jsx:573-604）、`FooterNav`（parts.jsx:607-621）、`SocialIcon`（parts.jsx:545-568）。
- 実装メモ：variant ごとに別 .astro ファイルに分割せず、`<Footer variant="home" />` の単一エントリで分岐させる（jsx 同様）。

### PageWrap
- `pages-1.jsx:4-20`。背景 / フォントの基底。Astro レイアウトに統合する想定（独立コンポーネント不要）。

## Building block

### BearDoodle / BearSitting
- `assets/bear-doodle.png`（129×123）を `<img>` で表示。`size` 引数のみ意味を持つ（pose / color は互換用 no-op）。
- 配置：speech bubble の付近、card 隅、Hero 等。size は 36〜94 の範囲で使われる。

### HandBottle / HandGlass
- それぞれ `assets/hand-bottle.png` / `hand-cup.png`。透過 PNG を `<img>` で。
- 用途：ヘッダー左ロゴ脇 / フッター右下浮き / Contact フッター帯など。

### HeartIcon / HeartsRating
- `parts.jsx:26-53`。色 / サイズ可変。`HeartsRating` は `value`(0-5) / `max`(=5) / `showValue`(=true) を受ける。
- 実装メモ：MVP は **整数四捨五入**。半分塗り（half-fill）は将来課題（Sub評価は 0.5刻みなので Phase 4 以降に対応）。

### Cloud / SpeechBubble / WashiTape / Underline / PolkaDots / DotPattern / ScatterDecor
- 全て純 SVG / div。React 移植時に props 互換のまま持ち込む。
- 注意：`PolkaDots` は `React.useMemo` の seeded PRNG を使う（parts.jsx:406）。Astro SSR 時は乱数固定が必須なので **そのまま React アイランド** または **Build 時に座標展開して `.svg`** で吐く 2択。
- `ScatterDecor`（parts.jsx:335-364）も同様に seed 固定（`i * 137.5`）で SSR safe。

### RankNumber
- `parts.jsx:447-459`。`No.{n}` を Caveat italic で表示し、下に手書き波線。
- 実装メモ：Home Top3 / Ranking Top3 で再利用。inline style → CSS Modules に切り出す。

### BottlePlaceholder / ProductPhoto / PhotoPlaceholder
- これらは **モック専用のSVGプレースホルダー**。本番では microCMS から取得した実写を `<img>` / `<picture>` に置き換える。
- ProductPhoto の構造（背景グラデ + 影 + 散布ドット + ボトル + グラス + 小道具）は本番では「写真 + 細い枠 + 角丸」のみで再現。手書き感は外側の `WashiTape` / `BearDoodle` で出す。
- 実装方針：`<ReviewImage src={...} variant="card|hero|detail" />` で `aspect-ratio` を切り替える（5:7 / 16:9 / 自由 — 決定ログ §写真の縦横比）。

## Data UI

### ReviewCard
- `pages-1.jsx:224-272`。
- 構造：写真フレーム（左上に日付チップ / 右上に NEW バッジ）→ 本文（HeartsRating / タイトル / 一言 / タグ + ♡）。
- props（jsx 互換）：`r`（Review型）、`liked`、`onLike`、`dark`、`accent`、`illust`、`compact`。
- 実装メモ：本番は Astro Card.astro + `client:visible` の Like Button。Card 全体は静的、♡ ボタンだけ React。
  - Like 状態は localStorage 保存（暫定）。CMS にユーザー機能は持たない。

### FilterGroup / FilterRow / FilterCheck
- `pages-1.jsx:409-454`。Review一覧サイドバー専用。
- FilterRow：単一選択（カテゴリ）。FilterCheck：複数選択（味のタイプ・季節）。
- 実装メモ：状態は URL クエリで持つ（`?cat=...&mood=...&season=...`）。React アイランドで URLSearchParams を読み書き。
