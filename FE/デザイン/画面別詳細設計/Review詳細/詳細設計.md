> ソース：`claude-design/pages-2.jsx:4-174`、`uploads/03-review-detail.png`

## 1. ページ全体構造

```
<PageWrap label="04 review-detail">
  <SiteHeader active="review" />
  <Breadcrumb />                        // home › review › {商品名}
  <DetailMainSection>                   // 380 / 1fr / 280

  <SiteFooter variant="review-detail" />
```

## 2. セクション分解（上から順）

### S1. SiteHeader
- `active="review"`。

### S2. パンくず
- `padding: 0 40px 8px`、11px。`home › review › {r.name}`。

### S3. メイン
- `padding: 0 40px 40px`、`grid-template-columns: 380px 1fr 280px; gap: 28px; align-items: start`。

#### S3-L. ImageCol（380px）
- メインフレーム：`background: #fff`、border、`border-radius: 18px`、`padding: 20px`、`position: relative`。
  - `r.badge`（"NEW" 等）あれば左上に旗形ラベル：`top: 14px; left: -6px`、`clip-path: polygon(0 0, 100% 0, 92% 50%, 100% 100%, 0 100%)`、accent fill。
  - メイン写真：本番は `<ReviewImage variant="detail" src={r.heroImage} />`、`max-aspect-ratio: 3/4`、`object-fit: contain`、`height: 280px`。
  - 右上：SpeechBubble（11px）「濃くてまろやか、／幸せ…！」※本文は決定値ではなくプレースホルダー扱い、CMS フィールド `oneLiner` にすると重複。MVP は固定文 / または `r.oneLiner` を流用。
  - 左下：`BearDoodle(60)`、`bottom: 0; left: 10px`。
- サムネ 4 枚：`grid-template-columns: repeat(4, 1fr); gap: 8px; margin-top: 12px`。
  - 各 `<button>` で `border: 2px solid accent`（active）/ `1px solid #e0e8f0`、`border-radius: 8px`。
  - クリックでメイン写真切替（gallery[i]）。
- 一言まとめ：`SpeechBubble` 1個、本文テキスト：
  - 1行目「一言まとめ」（12px）
  - 2行目 `<strong>{r.oneLiner}</strong>` 13px
  - 3行目「特別な日に飲みたいご褒美カルピス！」※固定ではなく `r.body` の冒頭か別フィールドを当てるべき → 本番では `r.oneLineSummary`（任意）が無ければ非表示。

#### S3-C. CenterCol
- 日付 11px：`{r.date}`（`YYYY.MM.DD`）。
- h1 36px：`カルピス {r.name}`。
- HeartsRating（size 20、accent、value 表示あり）。
- h2 22px：`r.oneLiner`（accent カラー）。
- 本文：13px、`line-height: 2`、`r.body`（HTML）を `set:html` で。
- 2 カラム grid（`1fr 1fr; gap: 24px; margin-top: 24px`）：
  - **左：sub ratings**
    - 上端 dashed border（accent）。
    - 各行：`grid-template-columns: 70px 1fr 30px`、ラベル / heart行 / 数値。
    - `visibleSubRatings(r)` で空項目除外。0件なら左カラム自体非表示。
  - **右：おすすめの飲み方**
    - h4 12px「おすすめの飲み方」。
    - 3列 button grid：`そのまま 🥛 / 氷を入れて 🧊 / 牛乳で割って 🥛`。
    - active = `2px solid accent` + `background: #eaf4fc`。
    - 下：BearDoodle(28) + 「キンキンに冷やしてそのままが一番すき！」（accent、center）。
- **似ているかも？？**：
  - h3 14px。
  - 3 列 grid。各カードは小さい `<ReviewCard compact>` 互換：写真 90px + タイトル 11px + 一言 10px + HeartsRating(10)。
  - クリックで `/reviews/[similar.slug]`。

#### S3-R. ProductInfoAside（280px）
- `background: #fff`、border、`border-radius: 18px`、`padding: 18px`、`position: relative`。
- 上端 WashiTape 50px。
- h3「Product Info」（Caveat italic 16px、accent）。
- 写真ボックス（小）：`background: #f4faff`、`padding: 14px`、`border-radius: 12px`、内側 `<ReviewImage height={120}>`。
- 情報テーブル：
  - 各行 `grid-template-columns: 70px 1fr`、`padding: 6px 0`、`border-bottom: 1px dashed rgba(168,200,232,0.3)`。
  - 行：発売日 / 内容量 / タイプ（infoReleased / infoVolume / infoType）。
- 「公式サイト →」ボタン：`width: 100%`、accent border、ピル。`r.officialUrl` 必須、なければ非表示。
- タグ chips：`#新商品 #濃厚 #ご褒美`、各 `padding: 3px 10px; border-radius: 999px; background: #eaf4fc; color: accent; font-size: 10px`。
- お気に入りボタン：`width: 100%`、accent border、`HeartIcon` + 「お気に入りに追加」、active で fill 反転。

### S4. BackLinkRow
- `padding: 0 40px 30px`、`display: flex; justify-content: space-between; align-items: center`。
- 左：`<a>← 一覧に戻る</a>`（13px、accent）。`href="/reviews"`。
- 右：`<SpeechBubble>みつけてくれてありがとう〜！</SpeechBubble>`。

### S5. SiteFooter（variant=review-detail）
- 24px の薄い余白のみ。フッター帯はなし。

## 5. レイアウト詳細 + 実装メモ

### グリッド
| Section | 値 |
|---|---|
| メイン | `grid-template-columns: 380px 1fr 280px; gap: 28px` |
| サムネ列 | `grid-template-columns: repeat(4, 1fr); gap: 8px` |
| sub + 飲み方 | `grid-template-columns: 1fr 1fr; gap: 24px` |
| sub 行 | `grid-template-columns: 70px 1fr 30px; gap: 8px` |
| 似ているカード | `grid-template-columns: repeat(3, 1fr); gap: 12px` |
| Info テーブル | `grid-template-columns: 70px 1fr` |

### 実装メモ

- **client island**：
  - `<DetailGallery>`（メイン+サムネの選択切替）：React、`client:visible`。
  - `<DrinkMethodPicker>`：state、`client:idle`。
  - `<FavoriteButton>`：localStorage 同期、`client:idle`。
- **microCMS フィールドマッピング**：
  - メイン写真 = `r.heroImage` / サムネ = `r.gallery`（最大 4）。`gallery` が無ければサムネ非表示でメイン 1 枚のみ。
  - サブ評価 = `subAmasa / subKoisa / subSappari / subMilk / subRepeat`。`visibleSubRatings(r)` で空除外。
  - Product Info = `infoReleased / infoVolume / infoType`。
  - 関連 = `getSimilarReviews(r, all, 3)` の結果。
- **`r.body` リッチテキスト**：microCMS のリッチエディタが吐く HTML をサニタイズ（DOMPurify）して `set:html`。
- **404**：`getStaticPaths` で全 slug を発行、外れた slug は 404 へ。
- **OGP**：`og:image` = `r.heroImage.url + '?w=1200&h=630&fit=crop'`。
- **TODO**：関連 SKU 写真の調達方針（決定ログ §残TODO）。仕様としては `r.gallery[0]` を fallback、なければ `r.heroImage`。

## 6. モバイルレイアウト（@max-width: 768px）

ソース：`claude-design/pages-mobile.jsx` `MobileDetail`、`uploads/review-detail-mobile.png`。

- MHeader（`showBack=true`）+ MobileBottomTab（active=review）
- 3 カラム → 1 カラム。スタック順：パンくず → メイン写真 → サムネ 4 枚（横スクロール）→ 一言まとめ吹き出し → 日付 + h1 + 評価 → oneLiner → 本文 → サブ評価 → 飲み方 → Product Info → タグ + お気に入り → 「似ているかも？？」 → ← 一覧に戻る
- メイン写真：full-width、`aspect-ratio: 1/1` 程度（縦長すぎると圧迫感）
- サムネ：4 列 grid → `display: flex; overflow-x: auto`、各 60px
- サブ評価と飲み方：2 col → 縦並び（飲み方が下）
- Product Info：右 aside → 本文の下に full-width で挿入。タグは折返し可
- 「似ているかも？？」：3 col → 横スクロール（card 幅 140px）、または 1 col stack
- お気に入りボタンは sticky bottom-bar 風に常時固定する案もあり（実装は次フェーズ）
