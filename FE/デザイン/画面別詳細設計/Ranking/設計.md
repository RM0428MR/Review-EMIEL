# Ranking 設計

> ソース：`claude-design/pages-2.jsx` の `RankingPage`（177-305）、`uploads/04-ranking.png`

## 目的

これまでの全レビューから個人の「お気に入り Top 3」と、「さっぱり系 / 甘い系 / 夏に飲みたい！ / 限定・コラボ」のテーマ別 Top 3 を見せるランキング画面。SNS 連携と my favorite で読了感を出す。

## ユーザーフロー

1. ヘッダー nav の `ranking` から `/ranking` に到達。
2. ヘッダー右の評価基準カードで「何で評価しているか」を確認。
3. Top 3 の 3 等高カードを見て、気になれば詳細ページへ。
4. テーマ別ランキング 4 ボックスをザッピング、「もっと見る →」で対応する `/reviews?...` にジャンプ。
5. my favorite で運営者の一推しを把握 → SNS で交流。
6. SiteFooter（ranking variant）に SNS 案内 + Bottle。

## 表示要素（上から順）

| # | セクション | 主要素 |
|---|---|---|
| 1 | SiteHeader（active=ranking） | – |
| 2 | ヘッダー 3カラム | h1 ranking ♔ + 紹介 / Bear + SpeechBubble / 評価基準 card |
| 3 | TOP 3 | 3 等高カード（i=0 のみ accent border） |

| 5 | MY FAVORITE | my favorite 紹介 + SNS card（gradient） |
| 6 | SiteFooter（variant=ranking） | – |

## データソース

- Top 3：`listReviews({ orders: '-rating,-date', limit: 3 })`。
- テーマ別：build 時に全件取得 → クライアント側で 4 テーマ × 各 3 件にフィルタ：
  - さっぱり系：`mood includes さっぱり`、rating 上位 3
  - 甘い系：`mood includes 甘め OR 濃厚`、rating 上位 3
  - 夏に飲みたい！：`season === 夏`、rating 上位 3
  - 限定・コラボ：`cat === コラボ OR 期間限定`、rating 上位 3
- my favorite：`siteMeta.myFavoriteSlug` または Top 1 のフォールバック。

## 仕様確定事項

- **podium 高さ違いなし**（決定ログ）。3 等高カードを横並びで。
- i=0 のみ `border: 2px solid accent`。i=1,2 は通常 border。
- 「もっと見る →」のリンク先（決定ログ §残TODO）：
  - さっぱり系 → `/reviews?mood=さっぱり`
  - 甘い系 → `/reviews?mood=甘め,濃厚`
  - 夏に飲みたい！→ `/reviews?season=夏`
  - 限定・コラボ → `/reviews?cat=コラボ,期間限定`

## アクセシビリティ

- `<ol>` 基底のランキングセマンティクス（Top 3 / 各テーマ）。
- 評価基準 card は `<aside aria-label="評価基準">`。
- gradient SNS card 内のアイコンは `aria-label="Instagram"` 等を付与。
