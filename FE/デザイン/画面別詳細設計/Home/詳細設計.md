# Home 詳細設計

> ソース：`claude-design/pages-1.jsx:22-221`、`uploads/01-home.png`

## 1. ページ全体構造

```
<PageWrap label="01 home">
  <SiteHeader active="home" />
  <HeroSection/>
  <NewReviewSection/>
  <RankingSection/>
  <ArchiveStripSection/>
  <SiteFooter variant="home" />
</PageWrap>
```

- 背景：`#ffffff`（PageWrap の light モード基底）。
- ページ幅：1440px キャンバス基準、デスクトップ最大 1280px の中央寄せが望ましい（jsx は固定幅レイアウトのため、本番で max-width を入れる）。
- 縦長フルページ。スクロール 1 本。

## 3. スクロール構造

- 単一スクロール。各セクション間は `padding-bottom: 40px` 程度の自然な区切り。
- フルページ高さの目安：1440px 幅で約 2200〜2400px（jsx 実測ベース）。
- アンカーリンクは想定なし（NEW REVIEW の chip は filter、ranking 内 No.X は詳細遷移）。

## 5. レイアウト詳細 + 実装メモ

| Section | 横並び/縦並び | 値 |
|---|---|---|
| HERO | grid 3col | `grid-template-columns: 220px 1fr 240px; gap: 24px` |
| NEW REVIEW | flex header + grid 5col | `repeat(5, 1fr); gap: 16px` |
| RANKING | grid 2col | `1fr 280px; gap: 24px` / 内側 `repeat(3, 1fr)` |
| ARCHIVE strip | flex chips + grid 6col | `repeat(6, 1fr); gap: 12px` |

### 実装メモ

- **client island 化**：
  - NEW REVIEW のカテゴリ chips（state を持つ）→ `<CategoryChips client:visible />`。
  - 各 ReviewCard 内の Like ボタン → `<LikeButton client:idle />`。Card 本体は静的。
  - 年/月 chips は MVP 静的（クリック → `/archive?year=...` に遷移）。
- **microCMS フィールドマッピング**：
  - HERO 写真 = SiteMeta `heroImage` または最新 `Review.heroImage` の固定 1 枚（仕様確定 TODO）。
  - NEW REVIEW = `listReviews({ orders: '-date', limit: 8 })` を取り、client で 5 件絞る（カテゴリ切替で表示数が減ってもバッファあり）。
  - Top 3 = `listReviews({ orders: '-rating,-date', limit: 3 })`。
  - my favorite = `siteMeta.myFavoriteSlug` で `getReviewBySlug`。
  - ARCHIVE strip = `listReviews({ orders: '-date', limit: 6 })`。
- **画像最適化**：HERO は eager + LCP 候補、それ以外は lazy。`<picture>` で webp 優先。
- **フォント**：HERO の "カルピス" だけ `--font-logo` を当てる。他は `--font-display` (Caveat) と `--font-jp` (Klee One) で十分。
- **TODO**：about-me の bear avatar を実画像にするか円のみで残すか（決定ログ §残TODO）。RocknRoll One が読み込めない端末用に `M PLUS Rounded 1c` をフォールバック確認する。

## 6. モバイルレイアウト（@max-width: 768px）

ソース：`claude-design/pages-mobile.jsx` `MobileHome`、`uploads/Home-mobile.png`。

- ヘッダーを `<MobileBottomTab>` 込みで MHeader に切替（左ロゴ + 右 HandGlass = Drawer トリガー、scallop wave 12px）
- HERO：3 col → 1 col。タイトル → 写真（フル幅）→ about-me（縦並び）の順 stack
- HERO 写真：`aspect-ratio: 16/9` で固定、上端 WashiTape は両端維持
- NEW REVIEW：5 列カード → 横スクロール（`overflow-x: auto`）または 2 列 grid
- カテゴリ chip は横スクロール。「review archive →」リンクは右側に小さく
- RANKING：1fr+280px → 縦並び（Top3 を 1 列 stack、各 No.X は左に 60px 配置）。my favorite は下に full-width
- ARCHIVE strip：6 列 → 2 列 grid。年/月 chip は横スクロール、月 chip は折り畳み（クリックで展開）
- 全セクションの `padding: 0 40px` → `0 16px` に縮小、`gap` も 16px → 12px
- フォント：hero は `clamp(40px, 9vw, 56px)`
