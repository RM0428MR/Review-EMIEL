# Home 設計

> ソース：`claude-design/pages-1.jsx` の `HomePage`（22-221）、`uploads/01-home.png`

## 目的

「カルピスを愛しすぎている個人運営の架空のレビュー日誌サイト」のトップ。サイト全体の雰囲気を伝え、最新レビュー・ランキング・アーカイブへの導線を提供する。

## ユーザーフロー

1. 訪問者が `/` にランディング。
2. Hero でサイト名と運営者の人柄を 5 秒で把握。
3. NEW REVIEW セクションでカテゴリ chips を切替えながら最新 5 件を流し見、気になるカードをクリック → `/reviews/[slug]`。
4. RANKING セクションで Top 3 と「my favorite」を確認。No.1 カードクリックで詳細へ、または「ranking ♔」リンクから `/ranking`。
5. REVIEW ARCHIVE strip で年月 chips を切替えてアーカイブを下見し、「review archive →」で `/archive`。
6. フッター中央の Bear / Subscribe / Follow me で読了感を残し、SNS / メルマガ導線へ抜ける。

## 表示要素（上から順）

| # | セクション | 主要素 |
|---|---|---|
| 1 | SiteHeader | scallop wave、ロゴ（HandGlass + my/カルピス/review）、nav 6項目（active=home）、検索アイコン、HandGlass |
| 2 | HERO | 3 カラム grid（220 / 1fr / 240）：左=サイトタイトル＋紹介、中=写真+吹き出し+クマ、右=about-me カード |
| 3 | NEW REVIEW | h2「new review」+ Underline / カテゴリ chips（5）/ 「review archive →」/ 5列カードグリッド |
| 4 | RANKING | h2「ranking ♔」/ 1fr+280px の 2カラム：Top 3 等高カード（No.1〜3）/ my favorite カード |
| 5 | REVIEW ARCHIVE strip | h2「review archive」/ 年chips（7）/ 月chips（13）/ 6列カードグリッド |
| 6 | SiteFooter（variant=home） | scallop wave + subscribe / Bear / follow me + 浮きBottle + nav + © |

## データソース

| セクション | 取得 |
|---|---|
| HERO | サイト固定（`src/content/site/about.md` + 固定画像） |
| NEW REVIEW | `listReviews({ orders: '-date', limit: 5 })`、カテゴリは追加 client filter |
| RANKING Top 3 | `listReviews({ orders: '-rating,-date', limit: 3 })` |
| RANKING my favorite | `src/content/site/about.md`（または `myFavoriteSlug` を SiteMeta に持つ） |
| ARCHIVE strip | `listReviews({ orders: '-date', limit: 6 })`、年/月 chip 切替は client side で再フィルタ（MVP は scrolling preview のみ、絞込は遷移） |

## アクセシビリティ

- HERO 画像は `alt=""`（装飾）、speech bubble の文言は本文（`<p>`）として読める。
- カテゴリ chips / 年chips は `<button role="tab">` ではなく `<a href="/reviews?cat=...">` への変換で SSR での履歴管理を優先（NEW REVIEW の chip だけは Home 内 client filter のため `<button>`）。
- カード全体を `<a>` で覆い、♡ ボタンだけ `event.stopPropagation()` でリンク遷移を抑止。
