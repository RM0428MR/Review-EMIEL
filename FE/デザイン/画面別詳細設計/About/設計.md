# About 設計

> モックなし。`claude-design/pages-1.jsx` の Home 内 about-me card と `pages-2.jsx` の Contact ヘッダー about-me を起点に、共通スタイル（02_デザイントークン.md / 03_コンポーネント設計.md）で起こす。

## 目的

サイト運営者と本サイトの趣旨を 1 ページで紹介する。Home / Contact の compact 版 about-me より深く、運営方針・ブランド注意・連絡先導線を含めた読み物にする。

## ユーザーフロー

1. ヘッダー nav の `about` または Home の `view more →` から `/about` に到達。
2. ヘッダーで運営者の人柄を把握。
3. 「このサイトについて」で趣旨を読む。
4. 「カルピスを愛しすぎた理由」「レビューの基準」「ブランドについての注意」の 3 トピックを読む。
5. 「お問い合わせ」CTA で `/contact` に遷移。

## 表示要素（上から順）

| # | セクション | 主要素 |
|---|---|---|
| 1 | SiteHeader（active=about） | – |
| 2 | ヘッダー 2 カラム | 左：BearSitting + h1 `about` + サブタイトル / 右：about me card（写真 or 円アバター） |
| 3 | 趣旨セクション | 「このサイトについて」h2 + 本文 + WashiTape 装飾 |
| 4 | 3 つのトピックカード | 「カルピスを愛しすぎた理由」「レビューの基準」「ブランドについての注意」（3 列 grid） |
| 5 | CTA バンド | SpeechBubble + 「お気に入りや感想を教えてね♡」 + `<a href="/contact">`「contact →」ピル button |
| 6 | SiteFooter（variant=home） | – |

## データソース

- `src/content/site/about.md`（Astro Content Collection）：
  - frontmatter：`title` / `avatar` / `catch`
  - 本文：Markdown（このページの「このサイトについて」 + 3 トピック）
- 表示時は `getEntry('site', 'about')` で取得し、 frontmatter 部分はそれぞれ slot へ流し込む。

## 仕様確定事項

- 「ブランドについての注意」は CLAUDE.md §プロジェクト概要 の文言を要約：「『CALPIS』は実在の登録商標です。本サイトは個人ファン日誌として運営しており、公式ロゴ・公式パッケージは使用していません。」
- アバター画像（決定ログ §残TODO）：MVP は `assets/bear-doodle.png` をピンク円背景に乗せた合成（Home の about-me と同じ）。実写は採用しない（個人サイトのプライバシー観点）。
- About には microCMS 連携なし（Content Collection のみ）。

## アクセシビリティ

- h1 1個 / h2 1個 / h3 ×3（トピック見出し）。
- アバター画像は装飾扱いの場合 `alt=""`、運営者特定要素なら `alt="このサイトの管理人"`。
