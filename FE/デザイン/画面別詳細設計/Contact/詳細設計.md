### 実装メモ

- **client island**：`<ContactForm client:load />`（Turnstile スクリプトを `<script src="https://challenges.cloudflare.com/turnstile/v0/api.js" defer>` で読み込む）。
- **POST**：
  ```ts
  // src/pages/api/contact.ts (Cloudflare Pages Function)
  export const POST: APIRoute = async ({ request, env }) => {
    const body = await request.json();
    if (body.company) return new Response(JSON.stringify({ ok: true }), { status: 200 }); // honeypot
    const t = await fetch('https://challenges.cloudflare.com/turnstile/v0/siteverify', {
      method: 'POST',
      body: new URLSearchParams({ secret: env.TURNSTILE_SECRET_KEY, response: body.turnstileToken }),
    }).then(r => r.json());
    if (!t.success) return new Response(JSON.stringify({ ok: false, error: 'turnstile' }), { status: 400 });
    await fetch(env.DISCORD_WEBHOOK_URL, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        embeds: [{
          title: `📩 ${body.subject}`,
          description: body.message,
          fields: [
            { name: '名前', value: body.name, inline: true },
            { name: 'メール', value: body.email, inline: true },
          ],
          timestamp: new Date().toISOString(),
        }]
      }),
    });
    return new Response(JSON.stringify({ ok: true }), { status: 200 });
  };
  ```
- **環境変数**（CFP の Production env に登録、Secret 扱い）：
  - `DISCORD_WEBHOOK_URL`
  - `TURNSTILE_SECRET_KEY`
  - `PUBLIC_TURNSTILE_SITE_KEY`（client から参照、`PUBLIC_` プレフィックス）
- **TODO（決定ログ §残TODO 解消）**：Discord Webhook URL は **CFP の Secret** に登録（git にはコミットしない）。`.env.example` には `DISCORD_WEBHOOK_URL=` 空欄で書く。
- **送信成功後の挙動**：成功 banner を表示し、フォームリセット。リダイレクトはしない。バナーは `aria-live="polite"`。
- **本文文字数**：上限は CMS に保存しないので青天井で OK（Discord 1 メッセージ上限 = 2000字）。フロント側で 2000字 cap を表示。
