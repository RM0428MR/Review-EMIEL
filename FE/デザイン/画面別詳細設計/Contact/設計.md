# Contact 設計

> ソース：`claude-design/pages-2.jsx` の `ContactPage`（438-584）、`uploads/06-contact.png`

## 目的

サイト訪問者から運営者へのお問い合わせ・感想・コラボ依頼を受け取る。Discord Webhook でスマホ通知させ、見落としを防ぐ（決定ログ §フォーム）。

## ユーザーフロー

1. ヘッダー nav の `contact` から `/contact` に到達。
2. ヘッダーで運営者の人柄と歓迎メッセージを把握、「about me」card で重複情報を見せる。
3. 左フォームで お名前 / メール / 件名 / メッセージ を入力。
4. 「送信する」 → Cloudflare Pages Function `/api/contact` に POST → Turnstile 検証 → Discord Webhook 投稿。
5. 成功で同ページに success banner を表示、フォームはリセット。エラー時はインライン表示。

## 表示要素（上から順）

## データソース

- about me card：`src/content/site/about.md`。
- フォーム送信先：CFP Function `POST /api/contact`。

## 仕様確定事項（決定ログ §機能ロジック）

### バリデーション
- name 必須
- email 必須かつ `RFC 5322 簡易形式` (`/.+@.+\..+/`)
- subject 必須
- message 5字以上

### Spam 対策
- Cloudflare Turnstile（`PUBLIC_TURNSTILE_SITE_KEY` を フロントに公開、`TURNSTILE_SECRET_KEY` をサーバ側で検証）
- Honeypot field（`<input name="company" hidden tabindex="-1">`）

### 送信フロー
```
[フォーム入力]
  → POST /api/contact { name, email, subject, message, turnstileToken, company }
  → Cloudflare Pages Function:
     1. company !== '' なら 200 ダミー応答（spam）
     2. Turnstile 検証
     3. Discord Webhook 投稿
     4. { ok: true } 返却
  → React: Success banner 表示 / フォームリセット
```

### エラー時
- 400/500 系：banner にエラーメッセージ。フォーム値はそのまま残す。
- ネットワーク：「通信エラー、時間をおいて再試行してください」。
- リダイレクトはせず同ページで結果を出す。

## アクセシビリティ

- `<form>` 内の各 `<label>` は `for` で input に紐付け。
- 必須マーク `*` には `aria-required="true"`。
- エラーメッセージは `aria-live="polite"`。
- 送信ボタンは送信中 `aria-busy="true"` + disable。
