# 404 設計

> モックなし。共通スタイル（02_デザイントークン.md）+ BearSitting + SpeechBubble + Cloud で、サイトの世界観を壊さないシンプルな迷子ページ。

## 目的

存在しないルートにアクセスしたユーザーを、優しい声がけと主要な遷移導線で救出する。日記サイトの空気を保つ。

## ユーザーフロー

1. 直接 URL / 古いリンクから 404 ヒット。
2. Bear と「このページは見つかりませんでした」の文言で状況を把握。
3. 4 つの導線（Home / Review一覧 / Ranking / Archive）から目的のページに飛ぶ。

## 表示要素（上から順）

| # | セクション | 主要素 |
|---|---|---|
| 1 | SiteHeader（active=なし） | active 引数を渡さない |
| 2 | メイン中央エリア | 大きい「404」+ サブタイトル「迷子になっちゃった…！」+ BearSitting + Cloud + SpeechBubble |
| 3 | リンクカード 4 列 | Home / Review一覧 / Ranking / Archive |
| 4 | 補助 | 「ホームに戻る →」ピル button |
| 5 | SiteFooter（variant=archive） | nav + © の最小フッター |

## データソース

- なし（静的）。

## 仕様確定事項

- HTTP ステータスコード 404 を Cloudflare Pages の `_routes.json` ベースで返す（Astro `src/pages/404.astro` を用意すれば自動）。

## アクセシビリティ

- h1 「404」は visual の大字、本文の `<p>` に「ページが見つかりませんでした」を別途置く。
- リンクカードは `<nav aria-label="主要ページへの導線">` で囲む。
