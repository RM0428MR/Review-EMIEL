# 404 詳細設計

> モックなし。SiteHeader + 中央エリア + リンクカード + SiteFooter (archive variant) の最小構成。

## 1. ページ全体構造

```
<PageWrap label="09 404">
  <SiteHeader />
  <NotFoundCenter />        // 大字 404 + bear + bubble + cloud + 戻るリンク
  <NotFoundLinkGrid />      // 4 列のショートカット
  <SiteFooter variant="archive" />
</PageWrap>
```

## 2. セクション分解（上から順）

### S1. SiteHeader
- props: `active` 未指定（どの nav 項目もアクティブにしない）。

### S2. NotFoundCenter
- `padding: 60px 40px 40px`、`text-align: center`、`position: relative`。
- 大字「404」：Caveat italic 160px、accent、`line-height: 1`、`letter-spacing: -4px`。
- サブタイトル 16px：「迷子になっちゃった…！」（ink-primary、`margin-top: 12px`）。
- BearSitting(120)：大字 404 の下に center。
- 右上に `<SpeechBubble color="#fff" stroke="accent">そのページは／みつからなかったよ〜</SpeechBubble>`、`position: absolute; right: 20%; top: 60px`。
- 左上に `<Cloud width={140}>`、`position: absolute; left: 18%; top: 40px`、半透明。
- 説明文 12px：「URL が間違っているか、削除された記事かもしれません。下のリンクから探してみてね。」
- ピル button「← ホームに戻る」（accent fill、white 字、`padding: 10px 24px`、`border-radius: 999px`）。

### S3. NotFoundLinkGrid
- `padding: 20px 40px 60px`。
- `<nav aria-label="主要ページ">` + h2 「ここから探してみてね」（Klee One 18px、ink-secondary）。
- 4 列 grid：`grid-template-columns: repeat(4, 1fr); gap: 16px`。
- 1 カード：
  - `<a>` で全体クリック可能。
  - `background: #fff`、border、`border-radius: 14px`、`padding: 16px`、`text-align: center`。
  - 上に該当 icon（HandBottle / HandGlass / RankNumber 風 / Cloud）。
  - h3 13px ラベル：Home / Review / Ranking / Archive。
  - 説明 11px：「最新のレビューへ」「レビュー一覧」「人気ランキング」「年月のアーカイブ」。

### S4. SiteFooter
- `variant="archive"`：CloudWave + `background: #cfe3f2; padding: 18px 56px`、nav + ©。

## 3. スクロール構造

- 単一スクロール、約 700〜900px（ファーストビュー 1 画面で完結）。

## 5. レイアウト詳細 + 実装メモ

### グリッド
| Section | 値 |
|---|---|
| 中央エリア | `display: flex; flex-direction: column; align-items: center; gap: 18px` |
| リンクカード | `grid-template-columns: repeat(4, 1fr); gap: 16px` |

### 実装メモ

- **Astro 404**：`src/pages/404.astro` を置けば Cloudflare Pages が自動で 404 ステータスを返す。`Astro.response.status` 設定は不要（CFP 側で処理）。
- **client island**：不要。
- **microCMS フィールドマッピング**：なし。
- **背景**：`background: #ffffff`（PageWrap の light）+ `<DotPattern density={0.3}>` を全面に薄く。

## 6. モバイルレイアウト（@max-width: 768px）

- MHeader + MobileBottomTab（404 は active 無し）
- 大字「404」：160px → `clamp(96px, 24vw, 160px)`
- リンクカード：4 列 → 2 列 grid
- Cloud / Bubble の絶対配置はモバイルでは省略（中央エリアの装飾は最小限に）
