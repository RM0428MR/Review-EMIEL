# Review一覧 設計

> ソース：`claude-design/pages-1.jsx` の `ReviewListPage`（275-407）、`uploads/02-review.png`

## 目的

これまでにレビューした全カルピスを一覧で見せ、カテゴリ・味のタイプ・季節で絞り込み、新着順 / 評価順で並び替えできる「カタログ画面」。

## ユーザーフロー

1. ヘッダー nav の `review` から `/reviews` に到達。または Home の `review archive →` から。
2. ヘッダーで件数（みつけた数 = 全 Review 数）を確認。
3. 左 Sidebar でカテゴリ（単一）/ 味のタイプ（複数）/ 季節（複数）を切替。
4. 上部の並び替え（新着順 / 評価順）と View toggle（▦ grid / ☰ list）で見せ方を変える。
5. グリッドからカードクリック → `/reviews/[slug]`。
6. ページネーション（1 / 2 / 3）でページ送り。

## 表示要素（上から順）

| # | セクション | 主要素 |
|---|---|---|
| 1 | SiteHeader（active=review） | – |
| 2 | パンくず | `home › review` |
| 3 | ページヘッダー | h1 `review` + 紹介文 / SpeechBubble + BearSitting / 「みつけた数」count card |
| 4 | コンテンツ | 左 sidebar（180px）+ 右 grid（1fr） |
| 5 | ページネーション | `‹ 1 2 3 ›`（grid 下） |
| 6 | SiteFooter（variant=review-list） | 帯なし、左下 BearSitting + 右下 HandBottle |

## データソース

- `listReviews({ orders: ... , limit: 18, offset: ... })`：最大 18件 / ページ。
- フィルタ：URL クエリ `?cat=&mood=&season=&sort=&view=&page=` を読む。
- カウント：`/api/reviews?fields=id&limit=0` で総件数（microCMS は totalCount を返す）。

## 仕様確定事項

- 並び替え：`新着順`（既定、`-date`）、`評価順`（`-rating,-date`）。
- View toggle：`grid`（既定、6 列）/ `list`（1 列、横長カード）。jsx は同一カードの並びだが、本番で `list` は写真左 + テキスト右の横長レイアウトに改める（決定ログ §残TODO）。
- ページサイズ：18 固定（→ 残TODO）。
- フィルタ未マッチ時：「該当する商品が見つかりませんでした」を BearSitting + 文言で表示（jsx には未実装、新規追加）。
- カウント表示：「{N}件の商品」（左上、フィルタ後の件数）。

## アクセシビリティ

- フィルタは `<form>` 内の `<input type="checkbox">` ベースに本番で書き換え（jsx は button 風）。`<fieldset><legend>カテゴリ</legend>` で意味付け。
- 並び替え `<select>` は jsx と同様にネイティブ select、`aria-label="並び替え"`。
- View toggle は `<button role="radiogroup">` + `aria-pressed`。
