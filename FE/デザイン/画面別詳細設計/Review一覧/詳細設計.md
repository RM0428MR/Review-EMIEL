## 2. セクション分解（上から順）

### S1. SiteHeader
- `active="review"`。共通仕様。

### S2. パンくず
- `padding: 0 40px 0`、`fontSize: 11px`、`color: #7a98b8`。
- 表記：`home › review`（`<a>` でリンク、現在地は plain）。

### S3. ページヘッダー
- `padding: 0 40px 20px`、`display: flex; align-items: center; gap: 24px`。
- 左：
  - `<h1 style="font-family: Caveat; font-style: italic; font-size: 56px; color: accent">review</h1>`
  - 紹介文 12px：「これまでに飲んだカルピスたちのレビュー一覧です。」
- 中：
  - `<SpeechBubble>気になるカルピスを<br/>見つけてね♡</SpeechBubble>` + `<BearSitting size={70} />`
- 右（marginLeft: auto）：
  - count card：`background: #fff`、`padding: 12px 24px`、`border-radius: 14px`、border。
  - 「みつけた数」（11px）→ 大数字（Caveat 36px、accent）→「種類」（10px）。

### S4. メイン
- `padding: 0 40px 40px`、`grid-template-columns: 180px 1fr`、`gap: 24px`。

#### S4-L. FilterSidebar
- `display: flex; flex-direction: column; gap: 18px`。
- 3 つの `<FilterGroup>`：
  - **カテゴリ**：`['すべて','定番','期間限定','コラボ','その他']`、単一選択 `<FilterRow>`。各行の右に件数。
  - **味のタイプ**：`window.MOODS`、複数選択 `<FilterCheck>`。
  - **季節**：`window.SEASONS`、複数選択 `<FilterCheck>`。
- 下に：`BearSitting(56)` + 小さい SpeechBubble「どれもおいしいよ〜！」。

#### S4-R. GridArea
- 上段：`display: flex; justify-content: space-between; align-items: center`。
  - 左：「{N}件の商品」（13px）。
  - 右：「並び替え：」 + select / 「表示：」 + view toggle（▦ ☰）。
- カードグリッド：
  - grid mode：`grid-template-columns: repeat(6, 1fr); gap: 12px`。
  - list mode：`grid-template-columns: 1fr; gap: 12px`、カードは横長（写真左 width:160px + テキスト右）。
  - 表示件数：18 件（jsx は `slice(0, 18)`）。
- ページネーション：
  - `justify-content: center; gap: 8px`。
  - `‹ 1 2 3 ›`、active は accent fill、その他は透明 button。
  - 30×30 円形 button。

### S5. SiteFooter（variant=review-list）
- 帯なし、左下 `BearSitting(70)` + 右下 `HandBottle(84)`。

## 5. レイアウト詳細 + 実装メモ

### グリッド
| Section | 値 |
|---|---|
| ページヘッダー | `display:flex; gap:24px; align-items:center` |
| Main | `grid-template-columns: 180px 1fr; gap:24px` |
| Card grid (grid) | `grid-template-columns: repeat(6, 1fr); gap:12px` |
| Card grid (list) | `grid-template-columns: 1fr; gap:12px`、card 内は `grid-template-columns: 160px 1fr` |

### 実装メモ

- **client island**：
  - `<ReviewFilters>`（チェック / カテゴリ / 季節）：URL クエリ書き換え（`history.replaceState`）→ `<CardGrid>` を再フィルタ。
  - `<ReviewSort>`（select + view toggle）：同上。
  - 結果メタ「{N}件の商品」は React state から再計算。
  - `<LikeButton>`：各カード内のみ。
- **microCMS フィールドマッピング**：
  - 全件取得は build 時に `listReviews({ limit: 100 })` で取り、client filter に渡す（量が増えたら検索 API を別途）。
  - count = `data.totalCount` を SSR で埋め込み。
- **URL クエリ**：
  - `cat=定番` / `mood=さっぱり,すっきり` / `season=夏,秋` / `sort=new|rating` / `view=grid|list` / `page=1`。
  - SSR で初期 chips active 状態を反映、hydration 後 client で更新。
- **空状態**：「該当する商品が見つかりませんでした」+ `<BearSitting size={80} />` + 「条件を変えてみてください」リンク（フィルタクリア）。
- **list view レイアウト**：MVP は grid と同形カード縦並びで OK（決定ログ §残TODO）。Phase 4 で横長レイアウト改修。
- **ページサイズ固定 vs 切替**：固定 18 件（決定ログ §残TODO）。

## 6. モバイルレイアウト（@max-width: 768px）

ソース：`claude-design/pages-mobile.jsx` `MobileReview`、`uploads/review-mobile.png`。

- MHeader + MobileBottomTab（active=review）。pagebreadcrumb は非表示
- ページヘッダー：3 col flex → 1 col stack。h1 は `clamp(36px, 8vw, 56px)`、Bear+Bubble は省略 or 下に小さく、count card は右下にコンパクト配置
- Sidebar 180px → **底からスライドインのフィルタシート**（フローティング「絞り込み」ボタンをクリックで開く）
- カードグリッド：6 列 → 2 列、`gap: 8px`
- 並び替え `<select>` と View toggle は上部右に横並び（list mode はモバイルでは隠し、grid 固定）
- ページネーションは下部、ボタン径 24px に縮小
