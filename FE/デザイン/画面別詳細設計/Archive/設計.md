# Archive 設計

> ソース：`claude-design/pages-2.jsx` の `ArchivePage`（308-435）、`uploads/05-archive.png`

## 目的

これまでに書いた全レビューを「年別 / 月別」の時系列で振り返れるアーカイブ画面。日記サイトとしての厚みを伝え、回遊を生む。

## ユーザーフロー

1. ヘッダー nav の `archive` から `/archive` に到達。
2. 上部 toggle で「年別で見る / 月別で見る」を選択。
3. 左 Sidebar で年代を切替（既定：2024年）。「すべての年代」「それ以前」も選択可。
4. 右の年見出し配下のグリッドからカードクリック → `/reviews/[slug]`。
5. 各カードには月バッジ（"5月" 等）が付き、時期が一目でわかる。

## 表示要素（上から順）

| # | セクション | 主要素 |
|---|---|---|
| 1 | SiteHeader（active=archive） | – |
| 2 | ヘッダー 3カラム | h1 archive + Bear / mode toggle + SpeechBubble / count card |
| 3 | コンテンツ | 左 sidebar 年リスト + Bear / 右 グリッド（年見出し + 6列カード） |
| 4 | SiteFooter（variant=archive） | nav + © のみ |

## データソース

- 全件取得：build 時に `listReviews({ orders: '-date', limit: 100 })`。
- 年別 grouping：`r.date.split('.')[0]`。
- 月別 mode（決定ログ §残TODO）：年関係なく「1月」「2月」… 12 グループに分けて表示。
- カウント：年別の場合は `byYear(y).length`、「すべての年代」は全件。

## 仕様確定事項

- 既定 mode：「年別で見る」。
- 既定 year：`'2024年'`（jsx 既定）。実装時は **最新年** を自動算出して既定にする。
- 「すべての年代」選択時は全年を縦に積む。各年セクションに見出し「{年}年 〜」+ 件数。
- 「それ以前」境界（決定ログ §残TODO）：MVP は **2020年以前** = それ以前として確定。`year < 2020`。
- 月バッジは年別カード左上に付く。**月別 mode**では年が同居するので、カード上部に「{年}.{月}」を別表示。
- 1 年に 12 件以上ある場合は 6列 grid を 2 行以上に折り返す。月バッジが重複して 1月のカードが 2 枚出るケースは許容（複数レビュー）。

## アクセシビリティ

- 年 sidebar は `<nav aria-label="年別">` の `<ul><li><a>`。
- mode toggle は `<button role="radiogroup">` + `aria-pressed`。
- 各年セクションは `<section aria-labelledby="year-2024">`。
