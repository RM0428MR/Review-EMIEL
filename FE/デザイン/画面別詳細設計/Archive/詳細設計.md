## 3. スクロール構造

- 単一スクロール、レビュー数次第で 2000〜4000px。
- 「すべての年代」を選んだ場合は年セクションが縦に積まれる：2024 → 2023 → 2022 → … → それ以前。
- 単一年選択時は該当年のみ。
- 各年セクション内は 6 列 × N 行で月バッジ付きカードが続く。

## 5. レイアウト詳細 + 実装メモ

### グリッド
| Section | 値 |
|---|---|
| ヘッダー | `grid-template-columns: 1fr 1fr 1fr; gap: 20px` |
| Body | `grid-template-columns: 180px 1fr; gap: 24px` |
| 年セクション内 | `grid-template-columns: repeat(6, 1fr); gap: 10px` |
| カード上の月バッジ | `position: absolute; top: -6px; left: 6px` |

### 実装メモ

- **client island**：
  - `<ArchiveModeToggle>`：URL `?mode=year|month`。React。
  - `<YearSidebar>`：URL `?year=2024`。React。
  - 切替時は `<ArchiveContent>` を再描画（client filter）。データは build 時に props で全件渡す。
- **microCMS フィールドマッピング**：
  - 全件 = `listReviews({ orders: '-date', limit: 100 })`。
  - `r.date` は `YYYY-MM-DD`（microCMS） → `r.date.split('-')` で year/month を抽出。
  - `parseInt(r.date.split('-')[0], 10) < 2020 → 'それ以前'`。
- **月別 mode の具体仕様（決定ログ §残TODO 解消）**：
  - sidebar は `['すべて','1月','2月',...,'12月']` に置換。
  - 右ペインは月ごとセクション、各セクションは年混在で日付降順。
  - カードは年.月 表記の小さなラベル + 商品名 + ♡。
- **「それ以前」境界**：`year < 2020` を「それ以前」グループに割り当てる（設計.md で確定済）。
- **空年**：該当年に 0 件なら「{年}年はレビューがありません」+ BearSitting + 「他の年も見てみてね」リンク。
