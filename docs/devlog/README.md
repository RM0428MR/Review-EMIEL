# DevLog（開発週報）

その週にやったこと・詰まったこと・次にやることを残す。書き口は緩めで OK、ポートフォリオで読まれる前提。

## ファイル名

`YYYY-MM-WN.md`（例：`2026-05-W1.md`）。

`WN` の数え方：その月の最初の月曜を W1 とする（毎月 W1 / W2 / W3 / W4 / W5）。

## テンプレ

```markdown
# YYYY-MM-WN（YYYY-MM-DD 〜 YYYY-MM-DD）

## やったこと
-

## 詰まったこと / 学んだこと
-

## 次にやること
-

## スクショ / リンク
- 関連 PR: #
- 関連 ADR: ADR-NNNN
```
