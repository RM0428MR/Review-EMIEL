## 詰まったこと / 学んだこと

- **「実装ソースの真」を最初に決めるのが重要**。claude-design と Pencil が並存していた状態で、どちらを正とするか曖昧なまま設計を始めると後で混乱する。最初の段階で ADR 化したのが正解だった。
- **CSS Modules vs Tailwind の選択を言語化**（→ ADR-0002）。手書き感の SVG / dashed / clip-path 中心のサイトでは utility クラスが破綻するため、Astro scoped style + tokens.css の組み合わせが最適。
- **モバイルは設計の最初から含めるべき**。後から「実装時にレスポンシブで対応」とやると、独立レイアウト前提のモックは media query で再現できない。最初から MHeader / MTabBar / NavDrawer + ブレイクポイント分岐を設計に組み込む形に。
- **HandGlass を hamburger trigger に統一**（→ ADR-0005）。装飾だった右上のカップを NavDrawer のクリックトリガーに昇格させ、デスクトップ・モバイルでナビ仕様を 1 系統に統一できた。
